# Налаштування AI-чату (сервер на Render + OpenRouter)

Що ти отримаєш: панель чату збоку від дошки, куди можна написати,
наприклад, «квартира в Антверпені, від 30 м², до 700€, район
Мерксем» — і за кілька секунд прийде список реальних оголошень з
Immoweb і Zimmo.

Безкоштовно (Render, безкоштовний рівень), крім самих запитів до AI —
OpenRouter бере невелику суму за кожне повідомлення в чаті (ти сама
поповнюєш баланс, скільки хочеш).

---

## Як це працює (коротко)

Дошка (`docs/index.html`) — статична сторінка, вона нічого сама не
рахує. Щоб чат міг прямо зараз запустити пошук і повернути відповідь,
потрібен окремий маленький сервер — `server/app.py` із цього ж
репозиторію. Дошка звертається до нього через інтернет.

Захист: сервер знає секретний **код доступу**. Кожен, хто хоче
скористатись чатом (ти або той, кому ти даси код), уводить цей код
один раз у браузері. Без правильного коду сервер відмовляє — тобто
ніхто сторонній не витратить твої гроші на OpenRouter.

---

## Крок 1. Акаунт OpenRouter і ключ

1. Зайди на <https://openrouter.ai> → зареєструйся.
2. Поповни баланс на невелику суму (кілька доларів вистачить надовго
   для особистого використання).
3. **Keys** → **Create Key** → скопіюй ключ (виду `sk-or-...`) —
   знадобиться на кроці 3. Показується лише один раз, тож збережи його
   десь у собі (не в публічний репозиторій!).

## Крок 2. Акаунт Render і сервіс

1. Зайди на <https://render.com> → зареєструйся (можна через GitHub-
   акаунт, яким ти вже користуєшся).
2. **New +** → **Web Service**.
3. Обери репозиторій `real-estate-aggregator` (Render попросить дати
   доступ до GitHub — дозволь).
4. Заповни форму:
   - **Name:** будь-яка назва, напр. `real-estate-chat`
   - **Root Directory:** `server`
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python app.py`
   - **Instance Type:** Free
5. **Create Web Service** — Render почне збирати й запускати сервер.
   Це займе хвилину-дві.

## Крок 3. Секрети сервера

У щойно створеному сервісі: **Environment** (зліва) → **Add
Environment Variable**, і так двічі:

| Key | Value |
|---|---|
| `OPENROUTER_API_KEY` | ключ з кроку 1 (`sk-or-...`) |
| `ACCESS_CODE` | будь-який код доступу, який ти вигадаєш (напр. `nastya-search-2026`) — саме його вводитимеш у чат |

Необов'язково:

| Key | Value |
|---|---|
| `OPENROUTER_MODEL` | назва моделі OpenRouter, якщо хочеш іншу за замовчуванням (`openai/gpt-4o-mini`) |

Після додавання змінних Render сам перезапустить сервіс.

## Крок 4. Адреса сервера

Угорі сторінки сервісу на Render — адреса виду
`https://real-estate-chat-xxxx.onrender.com`. Скопіюй її.

## Крок 5. Вписати адресу в дошку

1. Відкрий `docs/index.html` на GitHub (олівець **Edit**).
2. Знайди рядок:
   ```js
   var CHAT_BACKEND_URL = "";
   ```
3. Встав туди адресу з кроку 4 **з `/api/chat` на кінці**:
   ```js
   var CHAT_BACKEND_URL = "https://real-estate-chat-xxxx.onrender.com/api/chat";
   ```
4. **Commit changes**.

## Крок 6. Перевірка

1. Відкрий дошку. Зліва (або зверху на телефоні) — панель **🤖
   AI-пошук**.
2. Напиши щось на кшталт «квартира в Генті до 800€» → Enter.
3. Перший раз попросить код доступу — впиши той, що задала на кроці 3.
   Він запам'ятається в цьому браузері.
4. За кілька секунд має прийти відповідь і список оголошень.

**Якщо довго немає відповіді при першому повідомленні** — це
нормально: безкоштовний Render «засинає» після ~15 хв без
використання і «прокидається» до 30-60 секунд на перший запит.
Наступні повідомлення підряд будуть швидкими.

---

## Кому дати доступ

Скажи людині код доступу (`ACCESS_CODE`) — вона введе його при першому
повідомленні в тому самому чаті на дошці. Захотіла забрати доступ —
зміни `ACCESS_CODE` на Render (Environment) на нове значення; старий
код одразу перестане працювати для всіх.

## Якщо щось не так

- **«Чат ще не налаштовано»** — не вписана або невірна адреса в
  `CHAT_BACKEND_URL` (крок 5).
- **«Неправильний код доступу»** — звір `ACCESS_CODE` на Render і те,
  що ввела в чаті.
- **Довго немає відповіді** — почекай хвилину (сервер «прокидається»)
  і спробуй ще раз.
- **Не знайшов оголошень** — можливо, для такого поєднання критеріїв
  їх справді зараз немає, або назву міста написано так, що довідник
  Zimmo її не впізнав — спробуй іншим написанням (напр. англійською чи
  нідерландською назвою міста).
